# Пары

Офлайн-расписание занятий ВГЛТУ. Одна ссылка на всю группу: каждый выбирает свой код (ИС2-241-ОБ, ИС2-242-ОБ и любой другой), ставит сайт на экран телефона и открывает пары без интернета.

Дата «сегодня» считается заново при каждом открытии по часам телефона в поясе **Europe/Moscow (UTC+3)**: день, месяц и год. Приложение не оставляет вчерашнюю дату, если на сайте университета форма застыла на предыдущем дне.

## Как открыть одногруппникам

После включения GitHub Pages ссылка будет такой:

`https://furfantom1331fur.github.io/rasp-is2-241/`

1. Откройте ссылку.
2. Введите код группы. Подсказка по умолчанию — `ИС2-241-ОБ`, но можно выбрать любую группу из списка.
3. На экране «Сегодня» видны пары: время, предмет, аудитория (например `215Комп/Гл`), преподаватель, тип `лек` / `лаб` / `пр`, если он есть.
4. «Завтра» и «Неделя» ходят по настоящим календарным дням. Чужой день можно набрать полями **день / месяц / год** и нажать «Показать эту дату». Месяц стоит отдельной строкой, чтобы название влезало целиком. Кнопка «К сегодня» возвращает текущую московскую дату.
5. «Неделя» начинается с **сегодня** по Москве и идёт до **воскресенья** этой же календарной недели. Дни до сегодняшнего в список не попадают. Если открыта будущая неделя, видны все её дни с понедельника по воскресенье. Конец недели — воскресенье: в ответе расписания ВГЛТУ воскресенье есть отдельной строкой (часто «Нет пар.»), поэтому суббота за конец недели не принята.

Посещаемость открывается в разделе «Ещё». Как её включить — ниже.

## Добавить на экран

**Android, Chrome**

1. Откройте ссылку в Chrome.
2. Меню ⋮ → «Установить приложение» или «Добавить на главный экран».
3. Если Chrome готов установить сайт, в приложении есть кнопка «Установить».

**iPhone, только Safari**

1. Откройте ссылку в Safari (из Chrome на iPhone установка на экран не работает).
2. «Поделиться» → «На экран Домой» → «Добавить».

Та же подсказка есть внутри приложения.

## Офлайн

При первом открытии с интернетом service worker сохраняет страницу, значки и JSON расписания. Дальше «Сегодня» открывается без сети. Внизу экрана написано, когда копия была сохранена.

Пока телефон онлайн, приложение при запуске и при событии `online` снова запрашивает расписание. Выбранная группа запоминается в `localStorage`, расписание группы лежит и в `localStorage`, и в Cache API.

## Как обновить расписание

Интерактивное расписание университета ходит в `https://kis.vgltu.ru`:

- список групп: `https://kis.vgltu.ru/list?type=Group`
- пары: `https://kis.vgltu.ru/schedule?date=ГГГГ-ММ-ДД&group=КОД`

В ответе нет заголовка CORS, поэтому страница на GitHub Pages не может прочитать эти адреса из браузера. Приложение всё равно пробует прямой запрос (если университет откроет CORS, подхватится живой ответ). Пока ответа нет, показывается файл из `data/schedules/`.

Сопровождающий обновляет файлы у себя на компьютере и пушит их в репозиторий:

```bash
python3 scripts/update_schedule.py
python3 scripts/update_schedule.py ИС2-242-ОБ
python3 scripts/update_schedule.py --from 2026-09-21 --weeks 2 ИС2-241-ОБ ИС2-243-ОБ
```

Скрипт сам берёт понедельник текущей московской недели, если `--from` не указан. Каждое окно — 14 дней. Дата в запрос подставляется явно, а не из формы на сайте ВГЛТУ.

В репозитории уже лежат список всех групп и копии на ближайшие недели для `ИС2-241-ОБ`, `ИС2-242-ОБ`, `ИС2-243-ОБ` и `ИС2-244-ОБ`. Для другой группы запустите скрипт с её кодом и закоммитьте новый JSON. После пуша одногруппники получат файл при следующем открытии онлайн.

Проверка дат и разбора пар:

```bash
node scripts/selfcheck.mjs
```

## Посещаемость

Журнал повторяет личный кабинет [vgltu.ru/lc/attendance](https://vgltu.ru/lc/attendance): вход по **ID студента** и паролю, затем отметки за семестр или за выбранные даты. Браузер на GitHub Pages не может сам вызвать `vgltu.ru` из‑за CORS, поэтому запрос идёт через ваш Cloudflare Worker. Воркер только пересылает три адреса кабинета и больше ничего:

- `POST https://vgltu.ru/lc/login` — войти и получить сессию;
- `GET https://vgltu.ru/lc/site/ajax-attendance-by-date` — журнал (`beginDate` / `endDate`, сначала `ДД.ММ.ГГГГ`, если пусто — `ГГГГ-ММ-ДД`);
- `GET https://vgltu.ru/lc/logout` — завершить сессию на сайте.

Пароль **не записывается** в приложение и не уходит ни на какой адрес, кроме вашего Worker, а тот сразу отправляет его только на `vgltu.ru`. В `localStorage` остаётся идентификатор сессии `PHPFRONTSESSID` и последняя копия журнала. Копия видна без сети. Кнопка «Выйти» стирает сессию на телефоне и просит кабинет закрыть её тоже. Копия журнала после выхода остаётся, пока не войдёте снова и не обновите её.

Пока адрес Worker не задан, войти нельзя. Последняя копия, если она уже есть, всё равно открывается.

### Бесплатный Worker

1. Заведите бесплатный аккаунт Cloudflare.
2. Установите Wrangler: `npm install -g wrangler`, затем `npx wrangler login`.
3. В папке `worker/` выполните `npx wrangler deploy`.
4. Скопируйте адрес вида `https://rasp-attendance.<имя>.workers.dev`.
5. В приложении: «Ещё» → поле «Адрес Worker» → «Сохранить адрес». Либо впишите этот адрес в `js/config.js` (`WORKER_URL`) и обновите сайт. Принимаются только `https://….workers.dev`, `localhost` и хост из `WORKER_URL`.
6. Введите ID и пароль. После входа журнал запрашивается сам. Сессия переживает закрытие приложения.

Не вставляйте чужой адрес: пароль уйдёт туда. Код воркера пароль не логирует и не хранит.

## Напоминание

В разделе «Ещё» можно включить местное уведомление за 10 минут до следующей пары. Это Notification API в открытом приложении, без push-сервера. Если разрешение не дали или iOS его ограничивает, расписание всё равно работает.
